# Contributing

Case studies live under `case-studies/NNNN-short-slug/`.

## Adding a case study

1. Copy the template into a new numbered folder:
   ```bash
   cp -r _template case-studies/0002-your-slug
   ```
2. Write the study in that folder's `README.md`. Keep it honest — include what
   didn't work, not just the wins.
3. Put images, charts, and diagrams in the study's `assets/` folder.
4. Add a row to the **Index** table in the top-level [README](README.md).
5. Open a pull request.

## Style

- Prefer numbers with a baseline over adjectives.
- Keep each study skimmable: short sections, one table of metrics.
- Link code and sources rather than pasting large blocks.
